# 卷一「少年意气」（13 幕，约 5.8 万字含支线）

## 第一幕 觉醒之夜 —— 出身×4 独立开局（约 5,000 字）

**定位**：四种出身各写"被压到谷底"的开场，埋下全卷暗线。

场景（每出身 3~4 幕，汇合于青云山脚测灵前夜）：
1. 世家嫡子：成人礼退婚大戏（已扩写）→ 夜探祠堂（铜镜异动）
2. 寒门散修：破晓启程（与母亲诀别）→ 旧玉惊变（梧老登场）→ 山门难进（被慕容烈羞辱）
3. 魔道遗孤：雪夜遗孤（养父临终托镜）→ 夜奔（血魔宗爪牙追杀，梧老震退）→ 隐姓埋名（夜琉璃惊鸿一瞥）
4. 商贾之子：万金之子（当街被鞭）→ 千金买路（云裳初遇）→ 古道惊变（梧老护主）

**爽点**：退婚之辱、穷酸被欺、身份危机、当街打脸——四种"谷底"各有味道。
**flag**：sign_divorce / question_public / remember_face；stand_proud / swear_poor；swear_revenge / mourn_father / read_letter；buy_slap / note_slap / bet_murong…
**字数**：每出身 3~4 场景 × 约 700~900 字。

## 第二幕 古镜惊鸣 —— 金手指觉醒（约 4,000 字）

场景：梧老登场（按出身变体：铜镜/旧玉/碎镜/镇宅宝镜）→ 废灵根真相线索（「抽灵血祭」）→ 授《苍梧引气诀》→ **梧老夜课**（新增：第一次修炼的完整过程，梧老毒舌教学 + 初次引气体验）
**爽点**：废柴翻身起点；喜剧担当梧老立住形象（嘴毒心热、倚老卖老）。
**flag**：probe_wulao / test_wulao；skills: cangwu_yinqi。
**关系**：wulao +3~10（看选择）。

## 第三幕 青州古道 —— 兄弟结缘（约 4,500 字）

场景：邢烈与山匪缠斗（可帮/可等/可绕，**绕道即错过邢烈线**）→ 搏杀山匪（战斗）→ 不打不相识 → 陈玄鞭打卖糖葫芦的张伯 → 三分支（出手=战斗恶仆 / 买摊=灵石打脸 / 借刀=邢烈骂街）→ 苍梧城外收尾。
**爽点**：路见不平、并肩砍人；第一次"教训狗腿"。
**flag**：help/wait/skip_xinglie；buy_stall；let_xinglie；beat_山匪。
**关系**：xinglie（兄弟线启动）、chenxuan（宿敌线启动）。

## 第四幕 青云会武 —— 一鸣惊人（约 4,500 字）

场景：测灵台上雷光冲天（出身变体：寒门出贵子 / 遗孤潜藏 / 商贾扬眉 / 废柴回归）→ 全场哗然 → 苏小满初遇（桂花糖的甜香）→ 同门初识（石磊/林小乙/钱多多）→ 陈玄、慕容烈脸色铁青。
**爽点**：全场打脸名场面（本卷核心爽点之一）。
**flag**：meet_xiaoman；taunt_chenxuan；origin 变体文本。
**关系**：xiaoman（女主线启动）、石磊/林小乙/钱多多（同门线启动）。

## 第五幕 择师立道 —— 四线分途（约 5,000 字）

场景：青石大殿（四长老各有具象描写）→ 择师抉择 → **四线专属教学场景各 2 幕**（剑：柳长风讲剑意、剑冢观剑；丹：孙伯符讲药性、亲手炼丹；符：林清音讲笔力、画符入门；体：洪烈讲淬体、石阶负重）。
**爽点**：择师即定道，影响全游戏战斗风格与剧情。
**flag**：teacher 1~4（锁定师父线）。
**关系**：changfeng / sun_bo / lin_qingyin / hong_lie +10。

## 第六幕 内门立足 —— 立威与成长（约 5,000 字）

场景：入门第一课（师父线变体）→ 内门排挤（忍/战/借势三分支；战=战斗慕容烈）→ 修炼小成（苦修/悟道/服丹）→ **梧老夜课二**（新增：雷灵根修炼细节、梧老讲上古秘闻残片）。

**爽点**：立威打脸、苦修变强（数值可见）。
**flag**：endure_chenxuan / beat_murong_lie / call_zhu_chen；train_hard/enlighten/pill。
**关系**：shilei、lin_xiaoji、qian_duoduo、zhu_chen。

# 卷二「风起云涌」（12 幕，约 5.8 万字含支线）

## 第四幕 月下之约 —— 五线感情（约 5,000 字）

## 九、选项节奏与代入感标准（用户硬性要求）

1. **总原则**：一切建立在**文字够多、剧情够好**的前提上；选项**该出现时就出现**——在真正的决策点/岔路口/情感节点出现，可以多但必须恰到好处；**同时选项也不能太少**（每幕至少 5~8 个决策点，冲突/抉择幕更多），太少就没有参与感。密度随剧情自然起伏：日常幕少而精，冲突/抉择幕密而紧；绝不为了凑选项而截断剧情，也绝不让玩家长时间只能干看
2. **选项质量**：每个选项具体到动作与语境（"上前攥住鞭子"，而不是"同意/拒绝"）；关键选项（影响走向/关系/结局资格）不设提示，但后果必在未来场景回响
3. **代入感**：通篇第二人称"你"；感官细节（光/声/味/触）贯穿；关键节点必有心理独白（~…~）；对话严格贴合人物性格（梧老毒舌、小满活泼、清霜清冷、云裳精明）
4. **爽点节奏**：小爽（打脸/装逼/捡漏）与大爽（越级/突破/名场面）交替，每幕至少一个；每幕末留钩子（悬念/危机/期待）
5. **详略得当**：重要场景（大场面/情感节点/战斗高潮/关键抉择）精雕细琢（五感+人物细节+心理拉满）；过渡/日常小场景轻写带过（两三句点到即止）；**不是每个场景都堆细节**——全程高密度反而让玩家阅读疲劳，该浓则浓、该淡则淡

## 十、UI / 图鉴 / 地图详情打磨清单（拒绝半成品与单薄介绍）
