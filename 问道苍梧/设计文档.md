# 《问道苍梧》修仙模拟器 · 完整设计文档

> 版本：v1.0（定稿）｜类型：网页互动小说 / 选择型修仙模拟器｜平台：浏览器（手机·电脑通用）
> 目标：全通一周目 15~20 小时，总剧本 20 万字以上，5~8 个结局（细节动态组装），隐藏内容与多周目要素。
> 原创声明：仅借鉴经典修仙爽文的节奏框架（打脸逆袭、越级挑战、奇遇成长），剧情、人物、世界观全部原创，不抄袭任何已有作品。

---

## 一、核心体验承诺

1. **爽**：每幕一个「被压 → 蓄力 → 打脸」的完整爽点循环，越级打脸、身份反转、公开逆转。
2. **深**：身世之谜、古镜秘辛、宗门内奸、天地大劫四条暗线贯穿四卷；人物各有执念与代价。
3. **细**：选项影响当下战斗/对话/心境/关系/物品，性格三轴（侠义/功利/狠辣）长期固化主角为人，同一困境不同性格走出不同路；拒绝"一键跳几年"。
4. **长**：像电视剧一样分卷分幕，每幕多场景、多选择，支线丰富，阶段结局无缝续卷。
5. **笑**：毒舌镜灵梧老的吐槽、修仙日常趣事穿插调节奏。
6. **情感**：四位可攻略角色各有独立主题线（守护成长/剑心执念/立场真心/救赎牺牲），兄弟有同生共死也可能有背叛；中后期必须做出唯一抉择，被辜负者可能有代价。

## 二、世界设定：苍梧界

### 地理五域
| 域 | 风貌 | 势力 |
|---|---|---|
| 东荒 | 蛮荒、妖兽横行、散修聚集 | 妖兽山脉、散修集市 |
| 南疆 | 巫蛊瘴气、魔道渊薮 | 血魔宗、白骨教 |
| 西陲 | 沙海佛国、丹道圣地 | 丹鼎阁、沙海佛国 |
| 北漠 | 冰原、上古战场 | 古战场遗迹（封印所在） |
| 中州 | 修真正统、皇朝威仪 | 天剑宗、太清宗、万宝阁、大夏皇朝 |

### 境界体系
炼气一至九层 → 筑基（初/中/后）→ 金丹（初/中/后）→ 元婴（初/中/后）→ 化神（初/中/后）→ 渡劫 → 大乘 → 飞升。

### 上古秘辛（主线暗线之根）
上古苍梧仙帝以仙器「苍梧镜」为阵眼，将灭世天魔镇压于北漠九渊之下，随后仙帝不知所踪，苍梧镜碎裂散落人间。万年后封印渐松——正道有人监守自盗，魔道蠢蠢欲动，大夏皇朝觊觎仙缘，各方势力暗中布局。**主角的灵根被废、身世之谜、古镜觉醒，全部指向这场大劫。**

### 四大悬念主线
1. **身世之谜**：谁废了我的灵根？我到底是谁？（各出身线有不同答案，殊途同归）
2. **古镜秘辛**：梧老是谁？他与苍梧仙帝、与封印是什么关系？（卷3揭晓）
3. **宗门内奸**：身边谁在为魔道做事？（卷3大考验）
4. **天地大劫**：封印若破，苍梧界倾覆——主角如何选择？（卷4决战）

## 三、主角与开局（固定男性 + 深度自定义）

- **姓名**：自定（默认「沈青玄」）
- **出身 ×4**（各自独立开局剧本，之后汇入卷1主线）：
  1. **世家嫡子（退婚流）**：灵根被废三年遭退婚羞辱，成人礼上被当众打脸——退婚背后藏着废灵根的惊天黑幕
  2. **寒门散修**：出身贫寒，宗门收徒考核被百般刁难——从泥里爬起来的逆袭
  3. **魔道遗孤**：身世是最大秘密，正魔两道都在找他，养父临终托付古镜碎片
  4. **凡人商贾之子**：富可敌国但无修为，被修真二代当众欺压——用钱、用脑子、用拳头三重打脸
- **灵根**：金/木/水/火/土五行 + 变异（雷/冰/风/暗），自选或随机；隐藏「寂灭灵根」（与身世阴谋绑定，特殊条件激活，对应"废灵根"真相）
- **体质**：凡体 / 灵体 / 道体 / 魔体 + 隐藏「混沌体」（多周目/隐藏条件解锁，解锁隐藏结局）
- **性格起始**：侠义 / 功利 / 狠辣 三轴初始分配（6 点自由分配），影响前期对话选项与剧情细节
- **初始家底**：由出身决定（世家=灵石+丹药+法器；寒门=几乎一无所有+一件传家旧物；遗孤=古镜碎片+养父遗书；商贾=大量灵石+人情世故）

## 四、金手指：苍梧镜 + 镜灵「梧老」

- **苍梧镜**：上古仙器碎片所化的神秘古镜，寄宿毒舌残魂「梧老」。功能随剧情逐步解锁：推演功法、鉴宝识药、警示凶险、关键时刻出手护主（保命底牌）、封印相关秘辛。
- **梧老**：记忆残缺、嘴毒心热的上古残魂，自称记不清生前之事。提供搞笑吐槽 + 修炼指导 + 关键情报。他与苍梧仙帝、与封印的关系是卷3核心反转。
- **保命底牌制**：主角有梧老/古镜/贵人多重保命手段——失败=受伤、丢宝、掉境界等代价，不轻易死亡；坏结局只出现在剧情关键节点（可读档）。

## 六、剧情大纲

### 卷1「少年意气」（试玩版，六幕，单局 2~3 小时）

|---|---|---|
| 一 觉醒之夜 | 四种出身开局（退婚羞辱/考核刁难/身份危机/二代欺压） | 被压到谷底，埋下暗线 |
| 二 古镜惊鸣 | 古镜觉醒、梧老登场、授《苍梧引气诀》 | 废灵根真相初现、实力暴涨起点 |
| 三 青云会武 | 玄清宗收徒大会，灵根重测 | 当场打脸全场，结识小师妹、邢烈，陈玄结怨 |
| 四 立身之道 | 择师（剑/丹/符/体四线，影响后续）、内门排挤、坊市打脸 | 身份立足，送礼/支线铺开，感情线启动 |
| 五 青云秘境 | 组队探秘、多回合夺宝战、遭暗算（血魔宗卧底） | 生死一线，梧老出手，破筑基，战力质变 |

支线：坊市小事件、送礼好感事件、各角色专属事件、隐藏内容（混沌体/特定选择）。

### 卷2「风起云涌」
宗门大比（打脸升级）→ 正魔冲突初显 → 感情线深入（四位女主事件链推进）→ 遭魔道追杀逃亡 → 温如玉身世异动 → 突破金丹 → 阶段结局。

### 卷3「大争之世」
宗门变故、内奸揭露（温如玉嫌疑线收束，真相可能让你心痛）→ 魔道大举入侵 → 师父为徒挡劫 → 兄弟背叛或同生共死（关系系统大考验）→ 感情线强制抉择（唯一选择，被辜负者有代价）→ 梧老记忆觉醒（古镜秘辛反转）→ 突破元婴 → 阶段结局。

### 卷4「问鼎仙途」+ 结局篇
身世真相大白 → 封印松动、天魔威胁降临 → 宿敌决战（陈玄/幕后黑手）→ 化神→渡劫 → 结局分歧点 → 大结局。

## 七、结局树（5~8 个方向，细节动态组装）

| 结局方向 | 触发基调 | 说明 |
|---|---|---|
| 飞升证道 | 正道+心境+修为达标 | 真结局；陪伴者是本局伴侣，兄弟送行，动态文本 |
| 称霸一方 | 声望/势力路线 | 建立自己的宗门/势力，号令一方 |
| 携侣归隐 | 感情线+心境路线 | 与所选伴侣归隐；**每个伴侣有专属归隐变体** |
| 堕入魔道 | 狠辣+魔道路线 | 成为魔道巨擘；伴侣可能反目，兄弟可能决裂 |
| 身死道消 | 关键节点失败/被背叛 | 坏结局（可读档），也有"虽死犹荣"变体 |
| 苍梧镜主（隐藏） | 混沌体/多周目条件 | 继承苍梧仙帝遗志，重铸封印，守护苍梧界 |
| 重开一世（隐藏） | 特殊条件 | 轮回重启，二周目解锁新对话与新选择 |

**动态组装原理**：结局场景读取本局实际状态（伴侣、兄弟、性格、正邪、声望、物品、仇怨）现场拼装文本——方向定死，细节永远是玩家自己选的。卷1~卷3末尾各有 2~3 种阶段结局，带续章钩子，存档无缝接续。

## 八、系统设计

- **属性**：境界、修为、悟性、心境（心魔系统：心境低时修炼有风险）、声望、正邪值（-100魔~+100正）、灵石、魅力、攻防速（由境界+装备+功法推导）
- **性格三轴**：侠义/功利/狠辣——选项持续微调，长期固化；影响对话选项、盟友倾向、结局资格
- **功法**：凡/灵/玄/地/天/仙品阶；主修+辅修；提供被动与战斗秘技；隐藏功法条件解锁（卷1可选：剑/丹/符/体四系方向）
- **物品**：丹药（服用/突破/战斗回血/送礼）、法宝（武器/防具/饰品，装备与耐久）、材料、奇物（线索/任务道具）；背包分类管理，随时可查可操作
- **关系**：好感度+关系状态+喜好送礼+专属事件链；好感阈值触发援助/告白/背叛事件
- **战斗**：多回合策略战——每回合在 强攻/蓄势/防守/法宝/丹药/秘技 中选择，属性与资源决定胜负；失败有保命底牌（梧老/古镜/贵人出手），代价=受伤/丢宝/掉境界
- **心魔**：突破境界时的内心拷问场景（选项影响心境与性格），渡过=成长+心境提升，失败=境界跌落+心魔flag
- **搞笑**：梧老毒舌、同门日常、坊市闹剧、取名梗
- **危险提示**：高风险选项带非剧透标记「此路凶险」（设置可关）

## 九、UI 与体验（水墨暗色仙侠风）

- **布局**：中央剧情正文（打字机效果，点击加速）+ 底部选项；顶栏功能入口：状态/背包/关系/地图/图鉴/功法/存档/设置；电脑侧栏常驻精简状态，手机端抽屉
- **地图系统**：苍梧界五大域手绘感地图（CSS 绘制），势力标注；**迷雾机制**——未解锁区域黑雾，剧情推进渐亮，当前位置高亮；已解锁地点可查看简介，部分地点有小支线/小事件
- **背包**：分类卡片，详情弹层，服用/装备/赠送
- **状态**：角色卡（称号/境界进度条/像素头像）、属性、性格三轴、正邪值、灵石
- **关系**：角色卡（好感条/关系状态/已触发事件/喜好提示），可送礼
- **图鉴**：收集向（已遇敌人/丹药/地点点亮）
- **存档**：自动存档 + 多手动槽位（显示章节/境界/时长）；**跨设备**：导出存档码（文本）→ 另一设备导入即续玩
- **音效**：代码合成的轻量音效（打字/点击/战斗/突破/迷雾），设置可关
- **头像**：精细像素风头像（代码按角色配色与气质参数实时绘制，恒定不变），关键角色精细绘制，路人用文字卡
- **移动优先**：手机端为主布局，电脑端自适应

## 十一、技术架构

```
问道苍梧/
├─ index.html          入口
├─ css/style.css       水墨暗色仙侠主题
├─ js/
│  ├─ engine.js        核心：状态、场景解析、效果结算、条件判定（纯逻辑，可单测）
│  ├─ save.js          localStorage 存档 + 导出/导入存档码 + 版本迁移
│  ├─ audio.js         WebAudio 合成音效
│  ├─ combat.js        多回合策略战斗
│  ├─ map.js           地图渲染与迷雾
│  ├─ ui.js            全部界面：正文/选项/各面板/像素头像/弹窗
│  └─ main.js          启动与事件绑定
└─ data/
   ├─ items.js         物品库
   ├─ characters.js    角色库
   ├─ map.js           地图数据
   ├─ skills.js        功法库
   ├─ vol1.js          卷1剧本（分幕组织）
   └─ endings.js       结局组装模板
```

- **场景数据格式**：`{id, title, location, text, onEnter?, choices:[{text, hint?, cond?, effects?, goto?}], combat?, ending?}`；effects 数据驱动（stats/temper/rel/items/flags/equip/map/skills），条件用函数或数据谓词
- **存档格式**：版本号 + 全状态 JSON（base64 导出码）；版本迁移钩子保证**后续卷扩展后旧存档无缝续玩**（卷末阶段结局带续章钩子）
- **扩展机制**：剧本按卷分文件，新增卷=新增数据文件+把卷末钩子接到新卷首幕；存档里记录已见 flag，新内容按条件解锁

## 十三、扩充设定（v1.1 增补：设定丰满度）

### 丹药九品体系

## 十四、文字质量红线与字数目标（v1.2 修订）

### 字数目标（诚实量化）
| 卷 | 剧本量 | 单局阅读量 | 单局时长 |
|---|---|---|---|
| 卷1「少年意气」 | **5~6 万字** | 3~4 万字 | 4~5 小时 |
| 卷2「风起云涌」 | **5~6 万字** | 3~4 万字 | 4~5 小时 |
| 卷3「大争之世」 | **6~7 万字** | 4~5 万字 | 5~6 小时 |
| 卷4 + 结局篇 | **6~7 万字** | 4~5 万字 | 5~6 小时 |
| **合计** | **22~26 万字** | 阅读约 14~18 万字 | **全通一周目 18~22 小时** |

### 文字质量红线（每幕必查）
0. **风格公式（用户确认 v1.4）**：爽点为主（每幕至少一个打脸/逆袭/名场面）+ 情感细腻（甜为主）+ 轻喜剧（梧老吐槽/日常趣事）调节奏；**虐点按剧情需要自然出现**（背叛/离别/牺牲等转折处该出现就出现、该痛就痛，不刻意控制频率也不刻意回避），一切以剧情好看为准
1. **环境五感**：每幕场景至少写出 光/声/气味/触感 中的两项以上，拒绝干瘪的"空旷场地"式描写
2. **人物细节**：重要角色出场必须有 服饰/神态/习惯动作/口头禅 至少两项具象特征；情绪转折配微表情或小动作
3. **战斗分解**：多回合战斗需有过程描写（身法走位、招式拆解、灵力流转、受伤细节），不是一句"你赢了"
4. **心理独白**：关键节点必须有内心活动（~思考~ 标记），呈现选择的分量
5. **不跳剧情**：时间推进必须有事件填充（修炼日常、宗门生活、角色互动），严禁"数年弹指而过"式空转
6. **节奏**：每幕 3~4 个选项，选项文本具体到动作与语境

### 执行方式
按"每轮扩写若干幕 + 新增若干支线/角色事件"推进，直到各卷字数达标；进度如实记录于开发路线图。
